Face Gate

Video-based human authentication, running in your browser. The same pipeline as the Python app: Haar-cascade detection with OpenCV, then an LBPH recognizer.

🔒 Everything runs on this device. Frames, faces and the model never leave your browser, and a reload wipes them.

1 Take images

Enter an ID (numbers) and a name (letters), like the original app. It saves 60 face crops.

    2 Train images

    Builds an LBPH model: an 8×8 grid of local-binary-pattern histograms per face.

    3 Track images

    Distance below 50 counts as a match and is logged once per person. Above 75, the face is saved as unknown.
